# BGM files

This directory intentionally contains no copyrighted audio files.

Add legally usable files with these names:

- `lobby.mp3`
- `investigation.mp3`
- `tension.mp3`
- `result.mp3`

Then set the matching value in `manifest.json` to `true`. The browser only requests audio files that are explicitly enabled in the manifest, so the default project has no missing-file errors.
